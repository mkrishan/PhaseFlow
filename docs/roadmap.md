# Release roadmap

## 0.1: coherent scientific kernel

- Multi-clock experiment runner
- RRR feasibility dynamics
- Sparse percolation and component statistics
- Flow, transition, coarse-graining, symmetry, and intervention analysis
- Portable result bundles
- Optional Rust acceleration and Julia native interface

## 0.2: benchmark and plugin stabilization

- Versioned benchmark collections
- Generic ensemble and parameter-sweep interfaces
- Plugin conformance test kit
- Confidence intervals and finite-size scaling fits
- Additional projection, local-search, sampling, and gradient algorithms

## 0.3: learned-system experiments

- Adapters for activation and intervention traces
- Layer, training-step, and token clocks
- Batched feature-graph construction
- Causal intervention protocols
- Reference experiments for small neural networks

## 0.4: scalable execution

- Parallel run scheduling
- Columnar event export
- Chunked tensor and trajectory storage
- GPU tensor interchange
- Resumable and distributed parameter sweeps

## 1.0: stable platform

- Stable Python and plugin APIs
- Stable result schema and migration tools
- Prebuilt native wheels
- Registered Julia package
- Reproducible benchmark releases
- Long-term deprecation and governance policy
